# TODO Archive

Dieser Ordner enthaelt abgeschlossene TODO-Dokumente.

## Archiv-Regeln

- Nur erledigte TODOs gehoeren in dieses Verzeichnis.
- Die Dateien behalten ihren urspruenglichen Namen.
- Die Datei sollte vor dem Verschieben den Status `erledigt` tragen.
- Das Archiv ist rein historisch; neue Arbeit startet immer mit einer neuen oder weiterhin aktiven TODO in `server/docs/todos/`.
