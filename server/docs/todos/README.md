# TODO Management

Dieser Ordner enthaelt nur aktive TODO-Dokumente.

## Regeln

- Offene oder laufende TODOs bleiben direkt in `server/docs/todos/`.
- Erledigte TODOs werden nicht geloescht.
- Erledigte TODOs werden nach `server/docs/todos/archive/` verschoben.
- Vor dem Archivieren bekommt die Datei einen klaren Abschlussstatus, z. B. `Status: erledigt`.
- Das Archiv dient der Nachvollziehbarkeit und ist keine aktive Arbeitsliste.

## Benennung

- Aktive TODOs: `TODO_<THEMA>.md`
- Archivierte TODOs: urspruenglichen Dateinamen beibehalten

## Beispiel

- Aktiv: `server/docs/todos/TODO_REAL20_VISUAL_HARDENING.md`
- Archiviert: `server/docs/todos/archive/TODO_REAL20_VISUAL_HARDENING.md`
